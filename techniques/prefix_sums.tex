\section{Sumas parciales}
\whenuse{Arreglo est\'atico con muchas sumas de rango; tambi\'en para transformar
restricciones de subarreglos y construir diferencias.}

Usar un vector de tama\~no $n+1$ elimina el caso especial cuando $l=0$.
Los rangos son semiabiertos $[l,r)$.

\complexity{construcci\'on $O(n)$; consulta $O(1)$; memoria $O(n)$.}

\begin{lstlisting}[style=cpp]
struct PrefixSum {
    vector<ll> pref;

    explicit PrefixSum(const vector<ll> &a) : pref(a.size() + 1, 0) {
        fore (i,0,SZ(a))
            pref[i + 1] = pref[i] + a[i];
    }

    ll query(int l, int r) const { // suma de [l, r)
        return pref[r] - pref[l];
    }
};
\end{lstlisting}

En 2D: $P[i+1][j+1]=a[i][j]+P[i][j+1]+P[i+1][j]-P[i][j]$.
