\section{Rerooting DP}
\whenuse{Calcular una respuesta para cada posible ra\'iz de un \`arbol reutilizando
la DP de sub\'arbol y la contribuci\'on exterior.}

Usar cuando se necesita la respuesta para cada posible ra\'iz de un \`arbol.
Primero se calcula la contribuci\'on de hijos a padre; luego se propaga hacia
cada hijo la contribuci\'on de todo lo que queda fuera de su sub\'arbol.

Ejemplo: suma de distancias desde cada v\'ertice a todos los dem\'as.

\complexity{tiempo $O(n)$; memoria $O(n)$.}

\begin{lstlisting}[style=cpp]
struct DistanceRerooting {
    int node_count;
    const vector<vector<int>> &tree;
    vector<int> subtree_size;
    vector<ll> distance_sum;
    explicit DistanceRerooting(const vector<vector<int>> &input_tree)
        : node_count(input_tree.size()), tree(input_tree),
          subtree_size(node_count), distance_sum(node_count) {
        dfs_down(0, -1);
        dfs_up(0, -1);
    }
    void dfs_down(int vertex, int parent) {
        subtree_size[vertex] = 1;
        for (int to : tree[vertex]) if (to != parent) {
            dfs_down(to, vertex);
            subtree_size[vertex] += subtree_size[to];
            distance_sum[vertex] += distance_sum[to] + subtree_size[to];
        }
    }
    void dfs_up(int vertex, int parent) {
        for (int to : tree[vertex]) if (to != parent) {
            distance_sum[to] = distance_sum[vertex]
                             - subtree_size[to] + (node_count - subtree_size[to]);
            dfs_up(to, vertex);
        }
    }
};
\end{lstlisting}

\subsection{Ejemplo pr\'actico: elegir una capital}

Las ciudades forman un \`arbol y cada arista es una carretera:

\begin{verbatim}
A---B---C
    |
    D
\end{verbatim}

Se quiere construir un hospital en la ciudad que minimice la suma de distancias
hacia todas las dem\'as. Las respuestas para cada posible ciudad son:

\begin{verbatim}
Desde A: 0+1+2+2 = 5
Desde B: 1+0+1+1 = 3
Desde C: 2+1+0+2 = 5
Desde D: 2+1+2+0 = 5
\end{verbatim}

La mejor ciudad es \texttt{B}, porque su suma es $3$:

\begin{lstlisting}[style=cpp]
DistanceRerooting result(tree);
int best=min_element(result.distance_sum.begin(),
                     result.distance_sum.end())
         -result.distance_sum.begin();
\end{lstlisting}

Para una combinaci\'on gen\'erica no invertible, usar prefijos y sufijos de las
contribuciones de los hijos para excluir uno en $O(1)$.
