\section{Descomposici\'on por centroides}
\whenuse{Dividir un \'arbol en componentes balanceadas para contar caminos
 o mantener consultas de distancia, por ejemplo al v\'ertice marcado m\'as cercano.}

Un centroide de una componente de tama\~no $s$ es un v\'ertice cuya eliminaci\'on
deja componentes de tama\~no como m\'aximo $s/2$. Se elige un centroide y se
descompone recursivamente cada componente restante. El \'arbol de centroides
tiene altura $O(\log n)$; sus aristas no son necesariamente aristas originales.

\complexity{Construcci\'on $O(n\log n)$ tiempo y $O(n)$ memoria, incluyendo
la pila de los DFS. La profundidad de la descomposici\'on es $O(\log n)$,
pero un DFS auxiliar puede alcanzar profundidad $O(n)$.}

\begin{lstlisting}[style=cpp]
struct CentroidDecomposition {
    const vector<vector<int>> &tree;
    vector<int> size, parent;
    vector<char> removed;
    int root = -1;

    explicit CentroidDecomposition(const vector<vector<int>> &input_tree)
        : tree(input_tree), size(tree.size()), parent(tree.size(), -1),
          removed(tree.size(), false) {
        if (!tree.empty()) root = decompose(0, -1);
    }

    int calculate_size(int v, int previous) {
        size[v] = 1;
        for (int to : tree[v])
            if (to != previous && !removed[to])
                size[v] += calculate_size(to, v);
        return size[v];
    }

    int find_centroid(int v, int previous, int total) {
        for (int to : tree[v])
            if (to != previous && !removed[to] && size[to] > total / 2)
                return find_centroid(to, v, total);
        return v;
    }

    int decompose(int entry, int previous_centroid) {
        int total = calculate_size(entry, -1);
        int centroid = find_centroid(entry, -1, total);
        parent[centroid] = previous_centroid;
        removed[centroid] = true;
        for (int to : tree[centroid])
            if (!removed[to]) decompose(to, centroid);
        return centroid;
    }
};
\end{lstlisting}

\texttt{parent[v]} es el padre de $v$ en el \'arbol de centroides;
la ra\'iz tiene padre $-1$. La lista de adyacencia original no se modifica.
Al terminar, todos los v\'ertices quedan marcados en \texttt{removed}.

\begin{lstlisting}[style=cpp]
void centroid_example() {
    vector<vector<int>> tree = {{1}, {0, 2, 3}, {1}, {1, 4}, {3}};
    CentroidDecomposition decomposition(tree);
    cout << decomposition.root << '\n'; // 1

    // Ancestros centroides del vertice 4, incluyendo al propio 4.
    for (int v = 4; v != -1; v = decomposition.parent[v])
        cout << v << ' '; // 4 3 1
}
\end{lstlisting}

Para consultas de distancias, agregar la informaci\'on del problema en cada
centroide y recorrer estos ancestros. Las distancias deben medirse en el
\'arbol original, mediante LCA o precomput\'andolas durante la construcci\'on.

\warning{Requiere un \'arbol no dirigido conectado; los v\'ertices son
0-indexados. El constructor conserva una referencia: el \'arbol debe vivir
m\'as que la estructura. Los DFS recursivos pueden desbordar la pila en cadenas
largas; usar recorridos iterativos si los l\'imites lo requieren.}
