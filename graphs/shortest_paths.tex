\section{Dijkstra}
\whenuse{Caminos m\'inimos desde una fuente con pesos no negativos. Para pesos
0/1 usar 0--1 BFS; con negativos, Bellman--Ford.}

Distancias desde una fuente con pesos no negativos.
Para reconstruir caminos, descomentar las l\'ineas marcadas con
\texttt{Reconstruccion} y el ejemplo opcional. Guardar padres no cambia
el orden del tiempo de ejecuci\'on y agrega $O(V)$ de memoria;
reconstruir un camino cuesta $O(V)$ tiempo y memoria en el peor caso.

\begin{lstlisting}[style=cpp]
vector<ll> dijkstra(const vector<vector<pair<int,ll>>> &graph, int source
    // , vector<int>& parent // Reconstruccion: parametro de salida.
) {
    int n = graph.size();
    vector<ll> distance(n, LINF);
    // parent.assign(n, -1); // Reconstruccion: sin padre inicialmente.
    priority_queue<pair<ll,int>, vector<pair<ll,int>>,
                   greater<pair<ll,int>>> pending;
    distance[source] = 0;
    pending.push({0, source});

    while (!pending.empty()) {
        auto [dist_v, v] = pending.top(); pending.pop();
        if (dist_v != distance[v]) continue;
        for (auto [to, weight] : graph[v]) {
            if (weight < 0) throw invalid_argument("negative edge");
            if (distance[to] > dist_v + weight) {
                distance[to] = dist_v + weight;
                // parent[to] = v; // Reconstruccion: guardar predecesor.
                pending.push({distance[to], to});
            }
        }
    }
    return distance;
}
// Ejemplo de uso: grafo dirigido con pesos no negativos.
vector<vector<pair<int,ll>>> graph(4);
graph[0] = {{1, 4}, {2, 1}};
graph[2] = {{1, 2}};
graph[1] = {{3, 1}};
auto distance = dijkstra(graph, 0);
cout << distance[3] << '\n'; // 4

\section{0--1 BFS}
\whenuse{Caminos m\'inimos cuando cada arista pesa exactamente 0 o 1; evita el
factor logar\'itmico de Dijkstra usando una deque.}

Para pesos exclusivamente cero o uno.

\begin{lstlisting}[style=cpp]
vector<int> zero_one_bfs(const vector<vector<pair<int,int>>> &graph,
                         int source) {
    int n = graph.size();
    vector<int> distance(n, INF);
    deque<int> q;
    distance[source] = 0; q.push_front(source);
    while (!q.empty()) {
        int v = q.front(); q.pop_front();
        for (auto [to, weight] : graph[v]) {
            assert(weight == 0 || weight == 1);
            if (distance[to] > distance[v] + weight) {
                distance[to] = distance[v] + weight;
                if (weight == 0) q.push_front(to);
                else q.push_back(to);
            }
        }
    }
    return distance;
}
vector<vector<pair<int,int>>> graph(4);
graph[0].push_back({1, 0}); // 0 -> 1, costo 0
graph[0].push_back({2, 1}); // 0 -> 2, costo 1
graph[1].push_back({2, 0}); // 1 -> 2, costo 0
graph[2].push_back({3, 1}); // 2 -> 3, costo 1

vector<int> distance = zero_one_bfs(graph, 0);
cout << distance[3] << '\n'; // 1
\end{lstlisting}

\complexity{$O(V+E)$ tiempo y memoria.}

\section{Bellman--Ford}
\whenuse{Caminos m\'inimos con pesos negativos y detecci\'on de ciclos negativos
alcanzables; s\'olo para grafos moderados por su costo cuadr\'atico.}

Admite pesos negativos. Tras $V-1$ rondas, una relajaci\'on adicional indica
un ciclo negativo alcanzable desde la fuente. Usa \texttt{i128} internamente,
sin recortar distancias durante la detecci\'on. Devuelve \texttt{\{distancias,false\}}
o \texttt{\{\{\},true\}} si hay ciclo negativo alcanzable. Los inalcanzables valen
\texttt{LINF}; lanza \texttt{overflow\_error} si una distancia finita no entra en
\texttt{long long} o coincide con esa marca.
Para reconstruir, descomentar las l\'ineas marcadas \texttt{Reconstruccion} y
el ejemplo opcional: agrega $O(V)$ memoria; recuperar un camino cuesta $O(V)$.

\begin{lstlisting}[style=cpp]
struct WeightedEdge { int from, to; ll weight; };

pair<vector<ll>, bool> bellman_ford(
        int n, const vector<WeightedEdge> &edges, int source
        // , vector<int>& parent // Reconstruccion: parametro de salida.
) {
    assert(n > 0 && 0 <= source && source < n);
    // parent.assign(n, -1); // Reconstruccion: sin padre inicialmente.
    const i128 INF128 = (i128)1 << 126;
    vector<i128> distance(n, INF128);
    distance[source] = 0;
    for (int iteration = 0; iteration < n - 1; ++iteration) {
        bool changed = false;
        for (auto [from, to, weight] : edges) {
            if (distance[from] == INF128) continue;
            i128 candidate = distance[from] + weight;
            if (candidate < distance[to]) {
                distance[to] = candidate;
                // parent[to] = from; // Reconstruccion: guardar predecesor.
                changed = true;
            }
        }
        if (!changed) break;
    }
    for (auto [from, to, weight] : edges)
        if (distance[from] != INF128 && distance[from] + weight < distance[to])
            return {{}, true};
    vector<ll> result(n, LINF);
    for (int v = 0; v < n; ++v) if (distance[v] != INF128) {
        if (distance[v] < numeric_limits<ll>::min() ||
            distance[v] > numeric_limits<ll>::max() || distance[v] == LINF)
            throw overflow_error("distance outside output range");
        result[v] = (ll)distance[v];
    }
    return {std::move(result), false};
}

\complexity{$O(VE)$ tiempo y $O(V)$ memoria.}
\warning{Requiere v\'ertices 0-indexados y pesos \texttt{long long}.
No usar las distancias si el indicador de ciclo es verdadero.}

Ejemplo de manejo de salida: cada arista entra en \texttt{long long}, pero
la suma de dos costos m\'aximos no. El \texttt{catch} imprime \texttt{overflow}.

\begin{lstlisting}[style=cpp]
void bellman_ford_output_example() {
    ll weight = numeric_limits<ll>::max();
    vector<WeightedEdge> edges = {{0,1,weight}, {1,2,weight}};
    try {
        auto [distance, negative_cycle] = bellman_ford(3, edges, 0);
        if (negative_cycle) cout << "Ciclo negativo\n";
        else if (distance[2] == LINF) cout << "Inalcanzable\n";
        else cout << distance[2] << '\n';
    } catch (const overflow_error&) {
        cout << "overflow\n";
    }
}
\end{lstlisting}

\section{Floyd--Warshall}
\whenuse{Distancias entre todos los pares cuando $V$ es peque\~no; tambi\'en para
clausura transitiva o detectar ciclos negativos mediante la diagonal.}

Todos contra todos. Inicializar diagonal en cero, aristas en su peso m\'inimo y
el resto en \texttt{LINF}.

\begin{lstlisting}[style=cpp]
void floyd_warshall(vector<vector<ll>> &distance) {
    int n = distance.size();
    for (int k = 0; k < n; ++k)
        for (int i = 0; i < n; ++i) if (distance[i][k] != LINF)
            for (int j = 0; j < n; ++j) if (distance[k][j] != LINF)
                distance[i][j] = min(distance[i][j],
                    distance[i][k] + distance[k][j]);
}

bool negative_cycle_between(const vector<vector<ll>> &d, int a, int b) {
    for (int k = 0; k < (int)d.size(); ++k)
        if (d[a][k] != LINF && d[k][k] < 0 && d[k][b] != LINF)
            return true;
    return false;
}
\end{lstlisting}

\complexity{$O(V^3)$ tiempo y $O(V^2)$ memoria.}
