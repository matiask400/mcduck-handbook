Behavior and tradeoffs:
Floyd activates saturation once a negative diagonal is encountered before processing that intermediary. Until then its fast loop is unchanged.
Finite values need to fit strictly inside +/-LINF; V*max(abs(weight)) < LINF is a sufficient bound. Pairs affected by negative cycles must be queried via negative_cycle_between.
ODT: empty assignment returns before splitting; the existing initialized-domain contract remains.
Matrices: identity uses 1%mod and positive modulus is asserted, including exponent zero.
Integer binary search: int domain, ll bounds/midpoint/sentinels; l can be INT_MAX+1 and r can be INT_MIN-1.
Divide/conquer DP: trim unreachable option endpoints; leave an impossible midpoint at LINF; without a finite argmin, retain both option bounds.
DP finite-state monotonicity and representable finite sums remain required. Cost-impossible midpoints can force O(k*n^2) fallback; restrict computation to feasible state ranges when possible.
HLD, LowLink, rerooting and Euler LCA use O(n) explicit heap traversal storage. Tree queries and asymptotic complexity remain unchanged.
On random trees, HLD/LowLink/Euler LCA have a modest constant-factor overhead here; rerooting is faster. LowLink star also shows overhead; all raw samples are retained.
